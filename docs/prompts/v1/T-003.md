# T-003 — Sistem tier kualitas dan motion

Tujuan: menyediakan tier kualitas high/medium/low yang dideteksi otomatis, bisa diganti manual, tersimpan, dan menghormati prefers-reduced-motion.

File yang boleh disentuh:

- `lib/quality/**`
- `app/globals.css`
- `app/lab/**`
- `README.md`
- `docs/prompts/v1/T-003.md`

Deliverable:

- `lib/quality/config.ts`: ambang deteksi dan key penyimpanan.
- `lib/quality/detect.ts`: tipe `QualityTier`/`QualityPreference`, `detectQualityTier()` dan `parseQualityPreference()` murni.
- `lib/quality/store.ts`: store eksternal (useSyncExternalStore), baca/tulis localStorage, probe FPS 1 detik, listener reduced motion, set `data-quality` dan `data-motion` di `<html>`.
- `lib/quality/use-motion-tier.ts`: hook `useMotionTier` yang dipakai lintas komponen.
- Unit test deteksi tier dengan beberapa kombinasi sinyal.
- Halaman `/lab`: kontrol Auto/High/Medium/Low, status deteksi, dan showcase tambahan untuk tier medium.
- CSS tier memakai variabel agar scope `data-quality` bersarang menang sesuai scope terdekat.

Selesai jika:

- Tier terdeteksi otomatis dari `hardwareConcurrency`, `deviceMemory`, dan probe FPS.
- Pilihan manual tersimpan di localStorage dan dipakai setelah reload; Auto mengosongkan pilihan.
- `prefers-reduced-motion` terpantau dan menghasilkan `data-motion="reduced"`; transisi/animasi dinonaktifkan.
- `npm run lint`, `npm run typecheck`, `npm test`, dan `npm run build` lulus.
- `/lab` menampilkan high, medium, dan low; kontrol tier mengubah tampilan panel kontrol secara langsung.

Jangan:

- Menulis logika ADB.
- Menyentuh data tweak atau debloat.
- Menambah dependensi baru.
- Mengimplementasikan pengaturan lain di luar tier motion.

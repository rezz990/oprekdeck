# T-002 — Design tokens dan komponen dasar

Tujuan: menetapkan bahasa visual cockpit/HUD dan komponen dasar yang tampil benar di tier high dan low.

File yang boleh disentuh:

- `app/globals.css`, `app/layout.tsx`, `app/page.tsx`
- `app/lab/**`
- `components/ui/**`
- `docs/prompts/v1/T-002.md`
- `README.md`

Deliverable:

- Design token: warna dasar, warna risiko, tipografi display/mono, radius, glow, dan pola grid HUD.
- Komponen dasar: panel HUD, tombol (varian primary/secondary/ghost/danger), badge risiko (tweak dan debloat), gauge statis.
- Halaman `/lab` menampilkan semua komponen di dua scope: `data-quality="high"` dan `data-quality="low"`.
- Tier low menghilangkan grid, sudut HUD, glow, dan tick gauge; konten serta keterbacaan tetap sama.

Selesai jika:

- `npm run lint`, `npm run typecheck`, `npm test`, dan `npm run build` lulus.
- Halaman `/lab` tergenerate di static export dan memuat komponen pada kedua tier.
- Badge risiko memakai teks dan ikon, bukan warna saja; gauge memakai role meter; fokus keyboard terlihat.
- Tidak ada logika ADB dan tidak ada state tier global.

Jangan:

- Menulis logika ADB.
- Mengimplementasikan deteksi/persistensi tier otomatis (itu T-003).
- Mengisi data tweak atau debloat.
- Menambah dependensi baru di luar stack PRD.
- Menambahkan animasi berat atau animasi yang tidak menghormati `prefers-reduced-motion`.

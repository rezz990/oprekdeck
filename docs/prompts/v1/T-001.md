# T-001 — Inisialisasi proyek

Tujuan: menyiapkan fondasi Next.js statis yang lulus build, lint, typecheck, dan test kosong.

File yang boleh disentuh:

- `package.json`, `package-lock.json`
- `next.config.ts`, `tsconfig.json`, `eslint.config.mjs`
- `app/layout.tsx`, `app/page.tsx`, `app/globals.css`
- `vitest.config.ts`, `playwright.config.ts`, `e2e/**`
- `components/**`, `features/**`, `lib/**`, `data/**` (hanya struktur folder dan `.gitkeep`)
- `docs/PRD-OprekDeck-v1.md`, `docs/prompts/v1/**`
- `README.md`, `.gitignore`
- `AGENTS.md` (dikelola otomatis oleh Next.js)

Deliverable:

- Next.js App Router dengan `output: "export"`, TypeScript strict, Tailwind CSS, dan ESLint.
- Vitest dan Playwright terpasang dan terkonfigurasi.
- Struktur folder sesuai PRD bagian 12.
- Prompt master dan prompt task tersimpan di repo.

Selesai jika:

- `npm run build` menghasilkan static export di `out/`.
- `npm run lint`, `npm run typecheck`, `npm test`, dan `npm run test:e2e` lulus.
- Halaman root bisa dibangun dan Tailwind terpasang.

Jangan:

- Menulis logika ADB.
- Menambah dependensi di luar stack PRD bagian 12.
- Mengisi data tweak atau debloat.

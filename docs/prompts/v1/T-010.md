# T-010 — Riset dan penguncian library

Tujuan: membaca dokumentasi `@yume-chan` versi terpasang, mengunci versinya, dan mencatat API yang terverifikasi sebelum lapisan ADB ditulis.

File yang boleh disentuh:

- `package.json`
- `package-lock.json`
- `docs/adb-notes.md`
- `docs/prompts/v1/T-010.md`

Deliverable:

- Tiga library ADB dari PRD bagian 12 dipasang dengan versi exact: `@yume-chan/adb`, `@yume-chan/adb-daemon-webusb`, `@yume-chan/adb-credential-web`.
- `docs/adb-notes.md`: versi terpin, ringkasan API yang dibaca langsung dari README dan deklarasi TypeScript paket terpasang, alur koneksi WebUSB, penyimpanan kredensial, contoh minimal, dan batasan yang perlu ditangani di T-011.
- Contoh minimal koneksi + `shell` di dalam catatan, ditandai jelas belum diuji di perangkat nyata.

Selesai jika:

- Versi ketiga library dipin exact dan tercatat bersama tanggal riset.
- Tidak ada nama API yang ditulis tanpa bukti dari paket terpasang.
- Contoh minimal ada, atau catatan menyatakan jelas belum diuji di perangkat nyata.
- `npm run lint`, `npm run typecheck`, `npm test`, dan `npm run build` lulus.

Jangan:

- Menulis implementasi `lib/adb/**` (itu T-011).
- Mengimpor library ADB dari UI atau komponen.
- Menebak nama API dari ingatan atau dokumentasi versi lain.
- Menambah paket di luar tiga library ADB tersebut.
- Mengubah data tweak atau debloat.
